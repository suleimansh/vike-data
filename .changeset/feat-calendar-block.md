vike-blocks: add the `calendar` block (#435) — a dep-free, theme-native month grid for date selection, with no date library. `calendar('2026-07-15').min('2026-07-01').max('2026-07-31').weekStartsOn(1)` sets the initial selection, the selectable range, and the first column (0=Sunday default, 1=Monday), with `.month('YYYY-MM')` for the initially displayed month and `.name(...)` for a form field. Prev/next arrows step the displayed month; clicking a day selects it (an adjacent-month day jumps to that month). It tracks its own displayed month + selection (local UI state), so `value` is the initial selection and SSR agrees with the first client render; the date submit is the data/actions axis (#385), and `.name(...)` emits a hidden input so it submits with a form. Dates are plain `YYYY-MM-DD` strings (which sort in date order, so range checks are string compares); the grid always fills whole weeks with adjacent-month days. The grid math, range checks, and styles live in a shared `calendar-styles.js` module imported by both the React and Vue renderers, so the surface can't drift. Every color reads a vike-themes CSS var; composes inside the `field` block (#426), and is what `date-picker` (#436) drops into a popover.
